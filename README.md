# 苔光小筑 · 森林生活

一个可离线游玩的中文像素农场小游戏。从旧版像素农场增量发展而来，保留五种作物、商店、背包、装饰与邻里订单。

## 开始游玩

解压后直接用现代浏览器打开 `index.html`。无需安装、账号或网络。农场向北通往风铃森林，向东通往栗风小镇。

| 操作 | 方式 |
|---|---|
| 移动 | WASD / 方向键，或点击地图自动寻路 |
| 互动 | 靠近目标按 E，或点击目标走近互动 |
| 种植工具 | 点击地图下方工具按钮；1/2/3 切换种植、浇水、收获 |
| 背包 / 手札 | B / J，或点击顶部按钮 |
| 关闭面板 | Esc 或右上角关闭按钮 |
| 手机 | 点击地图，或使用地图下方方向按钮与互动键 |

先选择番茄种子，走到农田边操作。浇水后成长时间缩短 30%；收获会返还 1–2 颗种子。到订单板交付作物，报酬比直接出售高 50%（向上取整）。订单无时限，按六位邻居的固定顺序循环。

杂货铺出售种子、装饰、零食与礼物；背包中出售作物、使用零食和礼物，或在空农田旁摆放装饰。互动已摆放的装饰可收回。

## 存档与备份

自动保存在当前浏览器的 `localStorage`。旧版的金币、种子（包括 0/1 颗库存）、农田、背包和订单数量会迁移，迁移前保留原始副本。

设置中可导出/导入 JSON 存档。导入先校验，成功后替换；损坏或不支持的存档不会自动覆盖，自动保存会暂停，可导出原始数据。

离开页面暂停世界模拟，作物仍按记录的种植时间成长。换设备、浏览器或文件位置前，建议先导出存档。

## 验证

逻辑测试无需第三方依赖（Node.js 18+）：

```bash
node --test tests/game.test.cjs
```

浏览器测试需开发环境安装 Playwright 与 Chrome：

```bash
node tests/browser.cjs
```

也可用环境变量 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright。浏览器测试通过真实键盘/鼠标操作，从本地文件打开游戏，覆盖三处地图、种植浇水、购买、订单、刷新恢复和手机布局。

## 家园建设

森林中的木堆和石堆每处每天提供 3 份材料。到农场小屋旁休息可以进入下一天并补充森林资源，作物仍按现实时间生长。

农场工作台可制作林间花箱（木材 3）、午后长椅（木材 5、石料 1）、萤火路灯（木材 4、石料 3）。走到空装饰位旁打开背包摆放，再次互动即可收回。农田上原有装饰也能继续保留。

扩建告示牌依次需要 80/160/280 叶币，以及木材 3/5/7、石料 2/3/5。每级增加 5 块农田与 2 个装饰位，最终为 30 块农田、9 个装饰位。
