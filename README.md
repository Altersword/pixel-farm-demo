# 像素农场(demo)

一个基于 HTML、CSS 和 JavaScript 的像素风农场小游戏。

## 项目特色

- 种植多种作物：番茄、胡萝卜、玉米、草莓、西瓜
- 支持浇水加速生长
- 支持收获作物并出售换金币
- 商店系统：可以购买种子、装饰品、零食和礼物
- 背包系统：可查看并处理已拥有的物品
- 背景音乐：内置简易 Web Audio 音乐播放器
- 自动保存：游戏进度会保存在浏览器 `localStorage` 中
- 邻里订单：为 6 位森林邻居准备作物，交付获得比直接出售多 50% 的金币
- 适配手机竖屏，支持减少动态效果的系统偏好

## 运行方式

直接用浏览器打开 `index.html` 即可开始游戏。

如果你想用本地服务器打开，也可以在项目目录下运行任意静态服务器，例如：

```bash
npx serve
```

然后在浏览器中访问提示的地址。

## 操作说明

- 选择左下方工具栏中的工具
- 点击空地进行种植
- 点击作物进行浇水或收获
- 在右侧面板中切换种子、商店和背包
- 点击右上角按钮可以开关背景音乐
- 切到「订单」查看所需作物；收获后留在背包，凑齐即可交付
- 订单无时限，按固定顺序循环；完成数量与当前订单会随存档保留

## 存档兼容

旧存档会自动获得订单进度。种子库存为 0 或 1 时会保留真实数量，
只有旧存档中缺失的作物种类才补发 2 颗种子。摆放或收回装饰品会立即保存。

## 验证

无需安装依赖即可运行逻辑回归测试（Node.js 18+）：

```bash
node --test tests/game.test.cjs
```
