# 苔光小筑 · 森林生活 v1

一个温暖、可离线游玩的中文像素森林小游戏。从原版像素农场增量发展，保留五种作物、种子经济、商店、背包、装饰和邻里订单，加入可探索的小镇、森林、家园建设与邻居故事。

## 开始游玩

解压后直接用现代浏览器打开 `index.html`。无需安装、账号、网络或付费服务。首次打开有简短引导；农场向北是风铃森林，向东是栗风小镇。

| 操作 | 方式 |
|---|---|
| 移动 | WASD / 方向键，或点击地图自动寻路 |
| 互动 | 靠近目标按 E，或点击目标走近互动 |
| 农具 | 点击地图下方工具按钮；1/2/3 切换种植、浇水、收获 |
| 背包 / 手札 | B / J，或顶部按钮 |
| 关闭面板 | Esc 或右上角关闭按钮 |
| 手机 | 点击地图，或地图下方方向按钮与互动键 |

先选择番茄种子，走到农田边操作。浇水后成长时间缩短 30%，收获会留下 1–2 颗种子。订单报酬比直接出售高 50%（向上取整），没有截止时间，完成后自动换新。手札达成条件后，记得领取来信，故事才会翻页。

声音默认关闭，可在设置中开启。画面包含原创代码绘制的像素人物、六位动物邻居、五种作物成长阶段、树木、建筑和家具。昼夜每 12 分钟循环；设置支持减少动态效果。

## 采集、制作与家园

森林的木堆和石堆每处每天提供 3 份材料。到农场小屋休息会迎来下一天，补充材料和聊天/送礼次数；作物依旧按现实时间生长。世界模拟在关闭/离开页面及打开面板时暂停。

| 制作 | 材料 |
|---|---|
| 林间花箱 | 木材 3 |
| 午后长椅 | 木材 5、石料 1 |
| 萤火路灯 | 木材 4、石料 3 |

在农场工作台制作，走到空装饰位旁打开背包摆放，再次互动可收回。原有农田装饰也能保留和收回。

三级扩建分别需要 80/160/280 叶币、木材 3/5/7、石料 2/3/5。每级增加 5 块农田与 2 个装饰位，最终为 30 块农田和 9 个装饰位。

## 邻居与聚会心意

每天首次聊天 +1 好感，送一份喜欢的作物 +2（每天一次），完成对应邻居订单 +2。好感 3 收到一次纪念装饰，好感 6 解锁新的对话。

| 邻居 | 偏好 | 专属聚会心意 |
|---|---|---|
| 棉棉 / 兔子 | 胡萝卜 | 一份番茄、胡萝卜、玉米，做春日沙拉 |
| 栗栗 / 松鼠 | 玉米 | 按线索找回森林中四颗金松果 |
| 蜜朵 / 小熊 | 草莓 | 两份草莓与一份玉米，看准火候搅拌三次 |
| 河河 / 河马 | 西瓜 | 到森林池塘西侧的垂钓牌旁，成功收线并放流三次 |
| 枫叶 / 狐狸 | 番茄 | 解开 3×3 落叶滑块拼图，1–8 顺序，空格在右下 |
| 星灯 / 猫头鹰 | 草莓 | 记住并重现三段星光顺序 |

从邻居对话进入活动，或直接与果酱屋/垂钓牌互动。每份心意完成后，好感 +2，并收到 20 叶币；奖励只发一次。火候和浮标进入绿色区域时操作，失误不会扣食材。拼图、星光记忆可用 Tab/Enter 操作；星光答错可重新观察。

## 主线与自由生活

前四章引导探索三地并收获三株作物、采集制作、首次扩建和认识六位邻居。第五章需要两轮共 12 单订单、三级扩建、三种制作、六位邻居好感至少 3、家园装饰位摆放至少 3 件装饰，以及六份专属聚会心意。

条件达成后在手札领取来信，再去小镇聚会广场开启终章。结局后继续种植、交付循环订单、制作与布置家园。

30–60 分钟是最初的真人首玩设计目标，尚无真人计时样本。真实时间自动最短路径约 6 分 4 秒通关；真人探索、阅读和解谜时长会不同，游戏不设强制结束时间。

## 存档与备份

自动保存在当前浏览器的 `localStorage`。原版与早期版本的金币、种子（包括 0/1 颗）、农田、库存和订单数量会迁移，迁移前保留原始备份。已完成的早期版本结局不会被重置。

设置里可导出/导入 JSON。导入先校验，成功后替换并备份原数据。损坏存档不会自动覆盖，自动保存会暂停；可导出原始数据、导入有效存档，或保留损坏备份后启用新进度。换设备、浏览器或文件位置前，请先导出备份。

关闭页面时世界时间暂停，作物按原始种植时间继续成长。浏览器若禁止存储，会显示保存失败，仍可导出当前进度。

## 开发验证

逻辑与渲染测试无需第三方依赖（Node.js 18+）：

```bash
node --test tests/game.test.cjs
```

当前 27 项通过。浏览器验收需开发环境安装 Playwright 与 Chrome：

```bash
node tests/browser.cjs
node tests/ui-checks.cjs
node tests/playthrough.cjs
node tests/postgame.cjs
```

- `PLAYWRIGHT_MODULE`：可指定已有 Playwright 安装位置。
- `FOREST_PROFILE`：指定验收浏览器配置目录。新一轮全新验收请选择新目录；中断恢复沿用同一目录；结局后验证使用刚通关的同一目录。
- `FOREST_OUTPUT`：指定截图和日志目录，默认工作区 outputs。
- `MILESTONE=3`：让基础浏览器流程额外验证采集、制作、摆放、扩建与休息。

主线脚本只读取状态，并通过真实键盘/鼠标/游戏界面操作，不注入物品、不改存档、不调整时钟。通过 42 株收获、12 单订单、全部制作扩建、六位朋友、六份心意和聚会结局；另验结局后第 13 单、离线成长、关闭页面暂停世界、导入导出、手机控制、焦点、设置与 320–1440px 布局。无页面脚本错误，无远程资源请求。
